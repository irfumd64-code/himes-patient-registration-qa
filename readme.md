
# HIMES Patient Registration QA Demo

## About
A beginner-friendly healthcare software QA project.

## Features
- Patient registration demonstration page
- Required patient name validation
- Email validation
- JavaScript form handling
- Automated Playwright tests

## Testing
Run the tests using:

npx playwright test

## Purpose
This project is created for learning healthcare software testing and automation.

## Disclaimer
This is a demonstration project only. It does not store patient data and must not be used for real clinical work.
